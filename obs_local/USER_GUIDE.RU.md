# Руководство пользователя: подготовка материалов для OBS

Модуль готовит PNG из презентаций и материалов песен. Это руководство
описывает повседневную работу с уже установленным модулем.
Установка описана в [README](README.RU.md#установка-и-запуск).

## Запуск

Откройте терминал в папке установленного проекта и выполните:

```bash
./start_obs_local.sh
```

В активированном Python-окружении проекта можно использовать
`python -m obs_local`. Не запускайте системный Python без зависимостей проекта.
Если ваше меню отличается от карты ниже, проверьте обновления: старая
установленная копия не получает изменения рабочего репозитория автоматически.

## Карта меню

```text

├─ 1. Подготовить презентацию
│  ├─ Номер найденной презентации; 0 / Enter — отмена в главное меню
│  ├─ Если презентация не найдена
│  │  ├─ 1. Повторить поиск на Яндекс.Диске
│  │  ├─ 2. Открыть локальный PPT/PPTX → ввести путь
│  │  └─ 0 / Enter. Вернуться в главное меню
│  ├─ Способ обработки
│  │  ├─ 1 / Enter. Все слайды
│  │  ├─ 2. Категория по заметкам / изменить диапазон категории
│  │  │  ├─ 1. Проповедь
│  │  │  ├─ 2. Начало
│  │  │  ├─ 3. Молитва
│  │  │  └─ 0 / Enter. Назад к способу обработки
│  │  ├─ 3. Произвольные номера и диапазоны
│  │  ├─ 4. Подготовить несколько категорий
│  │  │  ├─ 1–3. Изменить диапазон категории и включить её в выбор
│  │  │  ├─ 4 / Enter. Конвертировать выбранные категории → подтверждение
│  │  │  ├─ 5. Выбрать / исключить категорию по номеру
│  │  │  └─ 0. Назад к способу обработки с сохранением правок
│  │  └─ 0. Отменить подготовку
│  │     Ввод слайдов: например 1, 3-5; 0 — назад
│  │     Enter — найденный диапазон, если он показан; иначе нужен ввод
│  └─ Подтверждение
│     ├─ 1 / Enter. Конвертировать выбранные
│     ├─ 2. Изменить выбор
│     └─ 0. Отмена в главное меню
├─ 2. Подготовить песни
│  ├─ 1. Прочитать программу
│  │  ├─ Если загрузка программы не удалась
│  │  │  ├─ 1. Повторить запрос
│  │  │  ├─ 2. Ввести путь к локальному файлу DOCX
│  │  │  │     Enter при вводе пути — назад к этому выбору
│  │  │  └─ 3 / Enter. Отменить, вернуться в подменю песен
│  │  └─ Если песня не найдена → альтернативное название; Enter — пропустить
│  ├─ 2. Обновить локальную папку песен
│  └─ 0 / Enter. Назад в главное меню
├─ 3. Настройки
│  ├─ Номер параметра → новое значение; Enter — оставить текущее
│  ├─ Отдельный пункт «Ввести токен Яндекс.Диска» → скрытый ввод
│  │     Номер зависит от количества параметров
│  ├─ Следующий пункт «Проверить обновления»
│  │  ├─ 1. Установить найденное обновление → завершить и перезапустить модуль
│  │  └─ 0 / Enter. Отмена установки → назад в настройки
│  └─ 0 / Enter. Назад в главное меню
└─ 0 / Enter. Выход
```

Введите цифру и нажмите Enter. Действие по пустому вводу зависит от диалога:
перед конвертацией Enter **подтверждает**, а в меню восстановления программы
**отменяет**. Ориентируйтесь на значение в квадратных скобках.

## Настройки перед работой

Выберите `3`, найдите параметр по названию, введите его номер, затем значение.
Изменения сохраняются сразу; комментарии в файле не удаляются.
Enter оставляет значение без изменений. Пустым вводом очистить параметр нельзя.

Модуль автоматически использует отдельный файл для текущей ОС:

| ОС | Файл в папке проекта |
|---|---|
| Linux | `obs_local/settings.linux.ini` |
| macOS | `obs_local/settings.macos.ini` |
| Windows | `obs_local/settings.windows.ini` |

При первом запуске файл создаётся из прежнего `obs_local/settings.ini` с
сохранением настроек. Далее файлы независимы: правьте файл своей ОС, а не
исходный шаблон. Обновления сохраняют эти локальные настройки.

Основные параметры:

| Параметр | Для чего нужен |
|---|---|
| `[YandexDisk] base_path`, `source_folder` | Каталог презентаций и папка служения на Яндекс.Диске |
| `[OBS Local paths] root_path` | Корень для готовых материалов |
| `[OBS Local paths] quality` | `standard`, `2k` или `4k` |
| `[SlideCategories] …_keywords` | Слова для поиска категорий в заметках презентации |
| `[Song preparation] priority_cloud_disk` | Источник программы: `google` или `yandex` |
| `program_google_url`, `program_yandex_url` | Отдельные публичные ссылки на программу |
| `program_url` | Совместимость со старыми настройками: ссылка для выбранного облака, если отдельная не задана |
| `local_zip_dir`, `local_pptx_dir` | Локальные библиотеки PNG ZIP и PPTX песен |
| `yandex_zip_png_paths`, `yandex_pptx_paths` | Пути удалённых библиотек песен; несколько путей разделяются `\|` |
| `cache_missing_yandex_song_zips` | `true` — дополнительно обновлять кэш всей удалённой библиотеки после чтения программы; `false` — не выполнять этот полный обход |
| `[Logging] log_dir` | Каталог журналов |

Относительные локальные пути считаются от корня проекта, не от папки
`obs_local`. В качестве значений путей вводите, например, `./song_assets/pptx`
или `/Users/operator/OBS/Материалы`. Не ставьте кавычки вокруг путей в настройках.
Общие URL каталогов песен не заменяют пути `yandex_…_paths`.

Для операций с удалёнными каталогами нужен OAuth-токен Яндекс.Диска.
Введите его через отдельный пункт настроек: символы при вводе не показываются.
Токен сохраняется в приватный `config.ini`, а не в файлы настроек.
Пустой токен не сохраняется. Не отправляйте токен в чат и не публикуйте
секретные конфигурации.

## Подготовить презентацию

1. В главном меню выберите `1`. При первом запуске модуль может запросить
   недостающие пути, качество и токен. Для качества: `1` — standard,
   `2` — 2k, `3` — 4k; Enter выбирает standard.
2. Модуль ищет презентации на ближайшее воскресенье. Выберите номер файла.
   Если файл не найден, повторите поиск или укажите локальный PPT/PPTX.
3. Выберите все слайды, категорию по заметкам или произвольные диапазоны.
   Пример: `1-4, 7, 9-11`. Номера начинаются с 1; нельзя выходить за число
   слайдов. Если категория не обнаружена, её диапазон можно задать вручную.
4. Проверьте выбранные слайды и категорию. Нажмите `1` или Enter для
   конвертации, `2` для изменения, `0` для отмены.
5. Дождитесь строки «Готово. Папка PNG для OBS» и скопируйте указанный путь.

Каждый запуск создаёт отдельную папку:

```text
<root_path>/<дата>/<имя презентации>/<идентификатор запуска>/<категория>/
```

Для всех слайдов категория называется `all`, для произвольного выбора —
`custom`, для категорий — `sermon`, `opening` или `prayer`.

Изменённые диапазоны сохраняются при возврате и переключении категорий
в рамках текущей подготовки этой презентации. После выхода или нового
запуска снова используются диапазоны из заметок; DOCX/PPTX и настройки
не изменяются.

Для одной категории используйте режим `2`: выберите категорию, задайте
диапазон и подтвердите конвертацию. Для нескольких используйте режим `4`:
найденные по заметкам категории уже отмечены; пункты `1`–`3` меняют диапазоны
и включают категорию, пункт `5` включает или исключает её по номеру.
Ненайденной категории сначала задайте диапазон. Затем выберите `4` и
подтвердите общий список. «Изменить выбор» вернёт к подготовке категорий,
не стирая диапазоны и отметки.

При пакетной обработке презентация конвертируется один раз. Категории
сохраняются в отдельных подпапках одного запуска (`sermon`, `opening`,
`prayer`), а итоговый путь указывает на их общую папку. Пересекающиеся
диапазоны сохраняются в каждой выбранной категории.

## Подготовить песни по программе

1. Выберите `2` в главном меню, затем `1` — «Прочитать программу».
2. Модуль скачает DOCX из выбранного облака (Google Docs экспортируется в DOCX) и извлечёт названия песен из таблиц
   программы на ближайшее воскресенье. Если URL не задан, предложит ввести
   публичную ссылку на файл. Она сохраняется только после успешной проверки
   скачанного DOCX.
3. Источники проверяются по порядку: локальные PNG ZIP, локальные PPTX,
   удалённые PNG ZIP, затем удалённые PPTX. Удалённый поиск требует настроенных
   путей и токена. PPTX конвертируются в PNG.
4. Проверьте результат поиска. Если материал не найден, введите другое
   название песни для повторного поиска или нажмите Enter, чтобы пропустить.
   Успешная альтернатива запоминается для следующих запусков.
5. Готовые песни расположены в `<root_path>/Трансляция/Песни/`, каждая —
   в отдельной нумерованной папке. Ненайденные материалы помечены
   `(не найдено)`; это не готовые слайды.

Имена файлов лучше делать соответствующими названиям песен. Неоднозначное
совпадение не выбирается автоматически. Составная и раздельная Unicode-запись
букв вроде `й` учитываются при сравнении.
Альтернативные названия, сохранённые до этого изменения, продолжают работать.

При публикации нового результата предыдущая папка песен сохраняется как
резервная копия с отметкой времени. Копии автоматически не удаляются.
Отмена загрузки программы не заменяет прежний опубликованный результат.

В пункте `3` → «Настройки» выберите `priority_cloud_disk`: `1` — Google,
`2` — Яндекс. Для Google Docs задайте `program_google_url` в формате
`https://docs.google.com/document/d/<id>/edit?usp=sharing`; для Яндекс.Диска
задайте `program_yandex_url`. Новые установки выбирают Google, старые
без этого параметра сохраняют прежний источник `program_url`. Разрешите просмотр
всем, у кого есть ссылка, и скачивание документа. Google-токен не нужен.
При ошибке доступа или странице входа вместо DOCX используйте меню ниже.
При ошибке перехода во второе облако нет: сразу показывается
меню восстановления. Выбор Google Docs меняет только источник программы,
не библиотеки песен.

### Программа недоступна

При HTTP 429, таймауте, сетевой ошибке или некорректном скачанном файле:

```text
1. Повторить запрос
2. Ввести путь к локальному файлу DOCX
3. Отменить, вернуться назад
Действие [3 — отмена]:
```

- `1` выполняет ещё один запрос. При HTTP 429 подождите перед повтором.
- `2` позволяет использовать файл, заранее скачанный вручную. Пример пути:
  `/Users/operator/Downloads/Программа собрания.docx`. В этом диалоге также
  принимается путь, заключённый в кавычки, а на macOS/Linux — пробелы,
  экранированные как `\ ` (например, при перетаскивании файла из Finder).
  Это также поддерживается при вводе пути PPT/PPTX. Файл должен быть корректным DOCX.
  Ошибочный путь или файл возвращает к выбору действия; Enter при вводе
  пути также возвращает к этому выбору.
- `3` или Enter отменяет подготовку и возвращает в подменю песен.
  Выберите там `0`, чтобы вернуться в главное меню.

Общая ссылка Яндекс.Диска может открывать страницу просмотра или CAPTCHA,
даже при HTTP 200. Для получения файла используется публичный API.
Автоматических повторов и обхода CAPTCHA нет.

Для локального DOCX или другой даты можно запустить сценарий отдельно
из окружения проекта:

```bash
python -m obs_local.prepare_songs \
  --program-file "/Users/operator/Downloads/Программа собрания.docx" \
  --date 2026-11-08
```

## Обновить локальную библиотеку песен

В подменю песен выберите `2`. Модуль проверит настроенные каталоги Яндекс.Диска
и создаст недостающие ZIP с PNG в `local_zip_dir`. Нужны токен и хотя бы один
удалённый путь. Обход вложенных каталогов ограничен тремя уровнями.

Это действие не читает программу собрания и не меняет выходную папку песен.
Валидные ZIP в кэше не перезаписываются. После работы показывается количество
созданных ZIP и ошибок; при ошибках проверьте журнал.

## Использовать результат в OBS

Откройте папку результата и проверьте изображения перед показом.
В OBS выберите соответствующий источник изображений/слайд-шоу и укажите
подготовленную папку или файлы согласно настройкам своей сцены.

Автоматическое изменение конфигурации OBS и переключение источников сейчас
не реализованы. Новая презентация имеет новый путь: его нужно выбрать в OBS
вручную. У песен путь публикации постоянный, но после замены изображений
проверьте, что источник OBS перечитал их. Модуль не редактирует сцены OBS.

## Обновить модуль

1. В главном меню выберите `3` → «Настройки», затем «Проверить обновления»
   (номер указан после пункта ввода токена). Только это действие обращается к GitHub.
2. Если есть новая версия, `1` устанавливает её; `0` или Enter отменяет.
3. После успешного обновления запустите модуль заново.

Отмена, ошибка проверки или отсутствие новой версии возвращают в настройки.

Настройки, токены и библиотеки сохраняются. При ошибке обновления следуйте
сообщению на экране; не удаляйте резервные копии пользовательских правок.
Системные приложения, например LibreOffice, этот пункт не обновляет.

## Логи и типичные проблемы

Журналы: `obs_local.log` — INFO и выше, `debug.log` — подробная диагностика.
Обычная консоль показывает предупреждения и ошибки. Пути по умолчанию:

| ОС | Каталог |
|---|---|
| Linux | `/dev/shm/pptx2png_tasks/obs_local/logs/` |
| macOS | `~/Library/Logs/pptx2png/obs_local/` |
| Windows | `%LOCALAPPDATA%/pptx2png/obs_local/logs/` |

На Windows без `LOCALAPPDATA` используется `~/AppData/Local/pptx2png/obs_local/logs/`.
Путь можно изменить через `[Logging] log_dir`. Для подробностей в консоли:
`./start_obs_local.sh --debug` (для подготовки песен).
На macOS последние записи можно посмотреть так:

```bash
tail -n 100 "$HOME/Library/Logs/pptx2png/obs_local/debug.log"
```

| Проблема | Действие |
|---|---|
| Программа не скачивается / HTTP 429 | Подождать и выбрать `1`, либо `2` для локального DOCX, либо `3` для отмены |
| Ссылка `docs.yandex.ru/view/...` не принимается | Взять публичную ссылку файла через «Поделиться» на Яндекс.Диске |
| Не найдена презентация | Проверить дату/папку на Диске; использовать локальный PPT/PPTX через предложенное меню |
| Не найдена песня | Проверить библиотеки и названия файлов; ввести альтернативное название |
| Нет токена / удалённого каталога | Проверить скрытый ввод токена и пути настроек своей ОС |
| Ошибка LibreOffice | Проверить установленное приложение; нестандартный путь задаётся через `PPTX2PNG_LIBREOFFICE_PATH` |
| Нет прав на запись | Выбрать доступные каталоги вывода, кэша и журналов |
| Меню отличается от руководства | Проверить обновления и перезапустить именно установленную копию проекта |

При сообщении об ошибке укажите действие, текст ошибки и относящийся к нему
фрагмент журнала. Не прикладывайте `config.ini` и не публикуйте токены.
